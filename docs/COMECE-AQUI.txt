LUMA 0.3.0-experimental — COMPANHIA DE AVENTURA
Minecraft Java Edition 26.2 | Fabric Loader 0.19.5 ou superior compatível

Você não precisa programar nem compilar para usar este pacote.
Não funciona no Minecraft Bedrock, celular, console, Forge ou NeoForge.
É necessário ter acesso oficial ao Minecraft Java Edition.
O pacote inclui IA própria de texto com uma memória local de informações autorais.
É uma opção experimental e começa desligada por padrão. A busca e o modelo
podem errar; os comandos funcionam com a IA desligada.

1. BAIXE E EXTRAIA O ZIP
Pacote: Luma-Fabric-26.2-IA-Propria-v0.3.0-Experimental.zip
Download:
https://raw.githubusercontent.com/lucasmac412/Mods/v0.3.0-experimental/downloads/Luma-Fabric-26.2-IA-Propria-v0.3.0-Experimental.zip
No Chrome, aperte Ctrl + J para ver o download e "Mostrar na pasta".
Se o Codex disser que não pôde baixar o artefato, use esse link do GitHub.
Clique com o botão direito no ZIP e escolha "Extrair tudo" ou equivalente.
Dentro da pasta extraída, abra a pasta "mods": há dois arquivos .jar.
Não descompacte esses JARs e não tente instalá-los com dois cliques.
Um ZIP com "src" e "gradle" é o código-fonte, não o pacote pronto.

2. PREPARE O MINECRAFT
No Minecraft Launcher oficial, abra Java Edition, escolha a versão 26.2,
inicie o jogo uma vez e depois feche-o.

3. INSTALE O FABRIC
Acesse: https://fabricmc.net/use/installer/
Baixe o instalador oficial. Selecione "Client", Minecraft 26.2 e Fabric
Loader 0.19.5 ou superior compatível. Instale com criação de perfil ativada.
No Launcher, selecione o novo perfil Fabric correspondente a 26.2.

O jogo precisa de Java 25. Se houver erro de Java ou de jdk.httpserver,
instale o JDK 25 completo: https://adoptium.net/temurin/releases/?version=25
No perfil Fabric, em Editar > Mais opções > Executável Java, selecione
o javaw.exe desse JDK no Windows, ou o java correspondente no Linux/macOS.

4. COPIE OS DOIS MODS
Feche o jogo. Se for atualizar, faça uma cópia da pasta "saves" para outro
local antes de usar a nova versão em um mundo importante.
Abra a pasta de jogo usada pelo seu perfil Fabric.
No Launcher: Instalações > perfil Fabric > Editar > Diretório do jogo.
Se o diretório estiver vazio, no Windows aperte Windows + R, digite
%APPDATA%\.minecraft e pressione Enter.
macOS: ~/Library/Application Support/minecraft
Linux: ~/.minecraft
Se usa outro Launcher, abra a pasta da instância selecionada.

Abra ou crie a subpasta "mods" nessa pasta de jogo.
Se já houver uma versão antiga da Luma ou do Fabric API que será trocada,
mova o JAR antigo para um backup FORA da pasta "mods".
Copie para ela OS DOIS JARs da pasta "mods" deste pacote:
- luma-companion-0.3.0-experimental.jar
- fabric-api-0.161.0+26.2.jar
Não deixe duas versões do mesmo mod na pasta.
O modelo e a memória local já estão dentro do JAR da Luma.
Não há outro modelo ou arquivo de memória para instalar ou configurar.

5. COMECE EM UM MUNDO NOVO
Abra o perfil Fabric 26.2. Crie um mundo Criativo com comandos ativados.
Faça backup antes de experimentar em um mundo importante.
Abra o chat com T e digite uma linha de cada vez:
/luma criar
/luma seguir
/luma falar Oi, Luma!
Para fazê-la esperar: /luma ficar
Para interromper uma tarefa: /luma parar
Para ajuda: /luma ajuda

6. EXPERIMENTE A IA PRÓPRIA DE TEXTO — OPCIONAL
No chat, digite uma linha de cada vez:
/luma ia ligar
/luma falar Como podemos começar nossa aventura?
Leia o aviso experimental e aguarde a resposta.
Para desligar o modelo: /luma ia desligar
Os comandos como /luma seguir e /luma construir continuam funcionando.

O gerador e os pesos são do próprio projeto. Uma memória local procura uma
nota relacionada à pergunta, e o modelo usa essa nota para gerar a fala.
A busca pode escolher uma informação de outro assunto e a geração ainda erra.
Você não precisa instalar Ollama, criar conta de IA, configurar API ou pagar.
A geração de texto acontece no computador e pode funcionar offline após
a instalação. Ainda é um modelo muito pequeno, distante da qualidade dos
modelos grandes usados com Ollama. Pode escrever frases erradas ou sem sentido.
Você pode experimentar perguntas como:
/luma falar Não sei por onde começar
/luma falar Uso madeira ou pedra?
Palavras como "não", "ou" e "talvez" não bloqueiam a conversa por si só.
Ainda não há garantia de uma resposta correta.

O modelo só gera falas. As ações do NPC continuam seguindo as ordens e regras
já programadas; a fala gerada não executa tarefas. Use /luma parar para
interromper uma tarefa. A IA não acrescenta construções novas nem joga uma
campanha sozinha. A memória não aprende automaticamente com suas conversas.

Esta versão gera texto no processador (CPU), em Java, sem usar a RTX 4060.
Ter 16 GB de RAM não garante qualidade de um modelo grande. Não compre
hardware nem serviços para esta versão. Se ficar lento, desligue a IA.

7. VOZ EM PORTUGUÊS
Em um mundo de um jogador, digite: /luma voz
Abra o link completo no Chrome ou Edge, no mesmo computador do jogo.
Clique em "Ativar conexão e voz". Para falar, clique no botão de microfone
e autorize seu uso. Você também pode digitar no painel.
A voz usa as vozes do sistema/navegador, sem dublagem humana gravada.
O reconhecimento pode enviar áudio ao fornecedor do navegador e exigir
internet. A leitura em voz alta também depende da voz escolhida.
Não criamos modelo próprio de voz ou reconhecimento do microfone.
Selecione uma voz pt-BR no painel; pode ser preciso instalá-la no sistema.
Não compartilhe o link. Para desligar: /luma voz parar

8. PRIMEIRO ABRIGO
Prepare terreno plano com área 5 x 5 livre e cinco blocos de altura vazios.
Retire até capim e flores. Fique perto dessa área e da Luma.
Segure 64 tábuas na mão e use /luma entregar.
Depois segure mais 32 tábuas e use /luma entregar novamente.
São 96 blocos no total. Agora use /luma construir.
Ela faz um abrigo fixo com entrada aberta, sem porta, cama ou tochas.
As trocas de itens exigem distância máxima de seis blocos.
